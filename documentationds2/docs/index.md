# The DS2 Software Documentation

To simplify the understanding of DS2 modules and the reference architecture, the modular components of DS2 have been divided into Tiers.

## Tier 0: DS2 Support Orientated

These represent a range of modules that are perceived as cross-cutting to the other tiers and their modules.

### Modules

* [CLM](https://ds2-eu.github.io/documentation/modules/CLM/)

* [MCL](https://ds2-eu.github.io/documentation/modules/MCL/)

* [SEC](https://ds2-eu.github.io/documentation/modules/SEC/)

## Tier 1: DS2 Marketplace and Deployment orientated

These support the acquisition, porting, and deployment of modules at participants or service intermediaries

### Modules

* [DMK](https://ds2-eu.github.io/documentation/modules/DMK/)

* [IDT](https://ds2-eu.github.io/documentation/modules/IDT/)

* [PORTAL](https://ds2-eu.github.io/documentation/modules/PORTAL/)

* [CONT](https://ds2-eu.github.io/documentation/modules/CONT/)

## Tier 2: DS2 In-Data Space Enablement

The modules facilitate consumer -provider participants in sharing their data. The modules are in general used by a single participant only in their local environment but in some cases, there are additional features to be used between data provider and consumer.

### Modules

* [ORC](https://ds2-eu.github.io/documentation/modules/ORC/)

* [RET](https://ds2-eu.github.io/documentation/modules/RET/)

* [DDT](https://ds2-eu.github.io/documentation/modules/DDT/)

* [MDT](https://ds2-eu.github.io/documentation/modules/MDT/)

* [CUR](https://ds2-eu.github.io/documentation/modules/CUR/)

* [DARC](https://ds2-eu.github.io/documentation/modules/DARC/)

* [E2C](https://ds2-eu.github.io/documentation/modules/E2C/)

* [DINS](https://ds2-eu.github.io/documentation/modules/DINS/)

* [DSHARE](https://ds2-eu.github.io/documentation/modules/DSHARE/)

* [DVM](https://ds2-eu.github.io/documentation/modules/DVM/)

## Tier 3: DS2 Inter Data Space Enablement

To an extent, the logic for this layer is the reverse of tier 2.  These modules can be allocated to the Tier 2 situation but their added value is much greater in a cross-sector, cross dataspace scenario.
